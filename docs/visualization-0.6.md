# 可视化方向调研与 0.6 概念（2026-11-10）

**状态**：P0 只读版已接进真机（0.7.3 已发布，2026-11-10）；旧「记忆」面板已下线，只保留「她的记忆」入口。
**图**：概念图（旧标题「她的一天」）`preview/dashboard-concept.png`；真机截图 `preview/live-now.png` / `live-memory.png` / `live-mind.png` / `live-bond.png`
**背景**：0.5.1 的记忆已经能算效用、能推用户模型，但面板还是「一列表格」；用户希望往可视化 / UX 方向更新。

## 一句话方向

把「记忆面板」从**数据库查询页**变成**她的观察窗**：

> 她现在怎么样 → 她记得什么 / 忘了什么 → 她为什么开口 / 没开口 → 我能改什么

不是加装饰，而是让 0.5 的「效用 / 用户模型 / 心理活动」第一次**看得见、能纠正**。

## 建议的界面结构

一张 **1440 宽** 的桌面面板（可响应到两列）：

```
┌ 顶栏：她的一天 · 日期 · 在线状态 · 此刻 / 记忆 / 心理 / 关系 ┐
├──────────────┬────────────────────────────┬──────────────┤
│ 此刻          │ 她的一天（06–24 时间条）    │ 为什么没开口   │
│ 头像/心情/精力 │ 日程块 · 现在 · 私信/@/记忆点│ 效用瀑布       │
├──────────────┴────────────────────────────┼──────────────┤
│ 她相信什么（记忆星图 / 规则块 / 最近记忆）  │ 你和她 + 她眼里的你 │
├───────────────────────────────────────────┴──────────────┤
│ 心理活动（卡片流：念头 / 暂缓 / 记住 / 被 @）              │
└──────────────────────────────────────────────────────────┘
```

### 1. 「此刻」Hero

- 头像、称呼、认识第 N 天；
- 心情（颜色/天气）、精力环、正在做什么、在哪；
- 今日主动 / 走神额度；
- 下一次日程、下一次可能主动的提示。

借 Tamagotchi / AI Town 的「角色状态」感，但保持克制，不做游戏化数值。

### 2. 「她的一天」时间条

- 06:00–24:00 横轴；日程块 + 实际活动 + 主动/被拦/日记/@ 标记；
- 点标记看当时发生了什么；
- 数据：`state.agenda`、`mind.jsonl`、`journal.jsonl`。

比 README 里那串「今天：…」更适合一眼看懂她过了怎样的一天。

### 3. 「为什么没开口」效用瀑布

这是 0.5 最有价值、也最不可见的部分：

```
由头 +0.21
黏人度 +0.03
基础打扰 −0.16
刚聊过 −0.28
刚主动过 −0.25
= −0.48 < 0.12 → 暂缓
```

- 直接读取 `computeUtility().terms`；
- 展示最近 1–3 次决策，可点开看「由头来自哪条记忆 / 哪个日程」；
- 让「她今天为什么没找我」变成可解释的，而不是玄学。

**需要改一处**：`decideProactive` 现在只把 benefit/cost/score 写进 mind refs，没存 `terms`；加一个 `state.lastProactiveDecision`（或 mind 里 JSON 化的 terms）即可。

### 4. 「她相信什么」记忆视图

三个层次：

1. **常驻块**：规则 / 他 / 我（person、self、rule），像 Letta 的 memory blocks 一样置顶；
2. **星图**：中心常驻块 → 内圈话头/约定 → 外圈经历；大小=重要度/强度，颜色=kind，淡出=衰减，连线=subjectKey/thread/tag；
3. **列表 / 时间线**：保留现有表格，作为无障碍与精确查找。

点击节点 → 右侧详情：全文、kind、scope、重要度/置信度、证据、版本历史、时间线；操作：**编辑 / 钉住 / 忘记 / 看相关**。

### 5. 「你和她」关系卡

- 认识天数、亲密度、共同记忆数、未完成约定；
- 「她眼里的你」：0.5 的用户模型（确定 / 习惯 / 也许 + 置信度 + 证据）；
- 最新日记一句、最近被提起的记忆。

这是用户最容易有情感连接的区域，也是「她到底记不记得我」的直观答案。

### 6. 「心理活动」卡片流

把表格换成时间倒序的卡片：图标 + 时间 + 一句话 + tag；筛选 chips（全部/主动/被拦/念头/记忆/夜间）；点「暂缓」卡片跳到效用瀑布。

### 7. 「记忆体检」

- 重复 / 疑似矛盾 / 快忘 / 隔离区 / 合并摘要；
- 写入日历热力图（最近 30/90 天）；
- 库大小、注入预算、上次巩固/反思。

### 8. 全局搜索

`/` 或 `Ctrl+K` 唤起；结果分 kind；点结果在星图里高亮；这是 peer 面板最实用的交互之一。

## 视觉方向（三选一，推荐 A）

| 方向 | 感觉 | 成本 | 风险 |
| --- | --- | --- | --- |
| **A. 手帐观察窗**（推荐） | 暖纸色、墨色、少量金/青；卡片像手帐页；安静、耐看 | 中 | 容易做得太平，需要靠星图和瀑布提神 |
| B. 星图 / 宇宙 | 深色、发光、轨道；和 memory-weight 很像 | 中高 | 容易炫技、标签拥挤、阅读性差 |
| C. 像素房间 | 房间/家具/角色点；AI Town 感 | 高（美术） | 和 Coopanion 桌宠本体重复，可能幼稚 |

推荐 **A 为底，B 只做记忆页的一个 tab**（不是整个产品变成星空）。

## 数据与接口缺口

现有 `invokeMemoryPanel` 只有 `overview / recent / mind / search / merges / unmerge`。建议新增：

- `timeline(days)`：日程、状态变化、mind 事件、日记、主动/被拦标记；
- `constellation(limit, filters)`：节点 + 边（按 subjectKey/tag/thread 生成，限制 300 节点）；
- `decision`：最近一次主动决策的 terms / score / threshold / 由头来源；
- `relationship`：profile、person、天数、承诺、计数、最新日记；
- `model`：`deriveUserModel()` 的 items（含 confidence/evidence）；
- `health`：stats、fading、重复/隔离/合并、字节、注入预算。

写操作（P1）：

- `updateRecord(id, text)`：升版本、保留旧版；
- `pin(id)` / `forget(id)`；
- `pauseProactive(until)`。

## 约束与风险

- **不引外部库**：Coopanion 面板是纯 JS；canvas 2D / SVG 足够，别上 three.js。
- **节点上限**：1097 条记录不能全画；服务端筛 200–300 条，按重要度/新近度取样。
- **可访问性**：颜色不能是唯一编码；提供列表视图和键盘操作。
- **明暗主题**：用 CSS 变量；暖纸色在深色模式下要换一套（米色 → 深棕）。
- **刷新**：现有 20s 轮询；星图不要每次重建，按数据指纹增量更新。
- **写操作需要确认**：编辑记忆会进提示词，必须有确认 + 版本回滚。

## 已实现（P0 只读，2026-11-10）

- 面板：`webUi().panels` 只保留 `life`（标题「记忆」，卡片「她的记忆」）；旧 `memory` 面板已删除。
- 数据：`dashboard`（此刻/日程/关系/模型/决策/时间线/心理）、`constellation`（最多 260 节点 + 同 subject/tag/thread/同日边）。
- 决策：`decideProactive` 返回 `terms`，`state.lastProactiveDecision` 记录完整拆解，瀑布有数据源。
- 前端：`src/webui/life.js` + `client.base.js`，`tools/build-webui.mjs` 把 life 内联进 `client.js`（Coopanion 只发一个 webUiClient 文件，不能 import 子文件）。
- 3D：2D canvas 上的球面投影 + 拖拽/滚轮/自动旋转/悬停/点击详情 + **全屏**，不引 three.js。
- 氛围：缓慢漂移的星云色团、闪烁星尘、上浮尘埃、中心微光；选中节点的连线金色流动高亮。
- 搜索/合并：0.6.2 搬入新面板；搜索接口返回全文/重要度/标签/证据，合并摘要可撤销。
- 概览/心理：0.6.3 搬入概览+最近 12 条、心理活动类型筛选；工具栏分层；时间条图例改成胶囊标签。
- 布局：0.6.4 起「她的一天」整行横排、心理活动单列多行；时间条事件标记带文字标签（0.6.5 去重）。
- 验证：真机 0.7.0 link，`073.png` / `layout-wide.png` / `overview-ui.png` / `mind-ui.png` / `mem-850.png` / `fullscreen3.png`；`node --test` 121 通过。
- 已知：编辑/钉住/忘记、体检仍是 P1；实验性认知入口随旧面板下线；决策卡在还没触发过主动时为空。
